# MyOS

[English](README.md) | **简体中文**

MyOS 教你的 AI 助手你是怎么判断、怎么做事的，让它按你的方式处理事情：守住你的底线，
运用你的原则和方法，并在你的某个老习惯对你不利时提醒你。放什么进去由你决定，存储保存在
你电脑上的私有文件夹中。助手读取的条目受其模型服务商的数据处理方式约束；可选的
`myos eval` 也会通过 Claude Code 把评测内容交给模型处理。

举个例子：你可能让助手回复一个扣着你押金不退的房东。一条已采纳的记录可以告诉它：
站在你这边据理力争，先把草稿给你看，发送留给你自己。这是在说明期望的行为，
并不是与不使用 MyOS 的助手进行过测量的对照结论。

MyOS 不是聊天记忆。它把你的判断明确记录下来，而不只依赖助手从过去的对话中推测。
MyOS 只存这一样东西：一小组经过你认可的规则、方法和习惯，每条都有出处。普通纠正，或你想以后再定的想法，先存为不参与回答的候选；
你又作出同类纠正时，或你说“过一遍我的候选”时，助手才问你要不要采纳。你说“记住这个”则直接采纳。
设计目标是让这些判断在模型进步后仍然有用。目前的小规模评估尚未证明 Skill 加按需读取
比包含相同内容的平铺笔记有稳定优势；计入维护成本后的长期收益也有待验证。
相关证据及限制见[探索地图](docs/exploration-map.md#e08--proving-usefulness-rather-than-successful-machinery)。

## 如何工作

```text
  你纠正它，或者教它
            │
            ▼
  助手更新一条条目  ──►  MyOS 存储（一个私有文件夹）
                                │ 自动刷新
                                ▼
  每次会话开始，助手的指令里都带着 MyOS 区块：
    • 你最重要的条目，全文
    • 其余已采纳的条目每条一行，写明什么情况下适用
                                │ 某个任务对上了某一行
                                ▼
  助手读取那条条目的全文，并照着用
```

每条条目是你的一个想法：助手必须守住的一条底线、一条原则、一个方法、一个需要留意的习惯，
或者关于你的一个事实。旧版本永远不会丢，你随时能看到一条条目是怎么变过来的。
