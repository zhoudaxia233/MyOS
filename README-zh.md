# MyOS

[English](README.md) | **简体中文**

**纠正你的 AI 助手一次。你点头之后，你用的每个助手都照做。**

![一次纠正先存为候选；第二次助手来问；你回答“采纳”后，Claude Code 和 Codex 同时得到这条规则](docs/demo.svg)

MyOS 保存的是“你希望被怎样帮助”的规则：你的底线、你怎么判断、你喜欢事情怎么做，
以及你希望被提醒的习惯。

- **每条规则都要你批准。** 一次纠正会连同你的原话存下来，先等着。只有你说了算，它才成为规则，
  助手不会自己猜了就当真。
- **一处维护，每个助手都用。** Claude Code 和 Codex 读同一套规则，改一次两边都更新。
- **它可以不顺着你。** 规则可以是你的一个习惯，比如事情一顺就扩大范围。助手会指出来，
  而不是跟着你走。
- **存判断，不存聊天记录。** 不存对话、日期和待办，只存会改变助手该怎么替你做事的东西。
- **是你的。** 存在你电脑上的一个私有文件夹里，每条规则的历史都在。助手读到的规则，
  和你的其他对话一样，由它的模型服务商处理。

## 安装

你需要 Claude Code 或 Codex，以及 [uv](https://docs.astral.sh/uv/)。

```sh
uv tool install git+https://github.com/zhoudaxia233/MyOS
myos setup          # 先看它打算改什么
myos setup --yes    # 确认修改
```

重启助手，对它说：*“和我一起设置 MyOS。”* 它会过一遍你已经给它写的规则，提出条目，
只保存你批准的那些。

## 哪些有证据，哪些没有

还没有证明的是：它会让你得到更好的回答。在一次私下评测里（55 个问题、一个模型、由另一个模型评分），
MyOS 比“把同样的规则放在一个普通文件里”覆盖了更多主人想要的要点，但没有依据的说法也更多。
更早的小规模对比没有发现稳定优势，维护规则要花的功夫也还没测过。MyOS 确定能给你的是控制权：批准、
所有助手共用一个来源、以及历史。详见
[探索地图](docs/exploration-map.md#e08--proving-usefulness-rather-than-successful-machinery)。
